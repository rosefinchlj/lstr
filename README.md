# lstr

Windows 启动器：自研文件索引 + 原生 Rust/egui 界面。核心是 **搜文件** 和 **启动应用**，目标是比 Listary 更安静、更快、更容易改。

常驻后台，双击 `Ctrl` 唤出：文件、文件夹、应用、浏览器书签、命令全在一个输入框里搜，选中回车即用。

## 特性

- **双击 `Ctrl` 全局唤出**：常驻托盘、不占任务栏；管理员窗口在前台时由提权 worker 中继热键，照样能唤起
- **自研索引，不依赖 Everything**：本机固定 NTFS 卷全量建索引，USN journal 增量 / `ReadDirectoryChangesW` 目录监视两种实时层；支持盘符级筛选
- **输入框即条件**：`date>2026-11-10:` / `size>10M:` / `path:D:\work` / `C:` / `a ` / `g ` 全部收成可见 chip（时间/大小/路径/盘符/范围/搜索）——`×` 删除、双击改回文本、`Ctrl+Z/Y` 撤回，条件之间 AND
- **路径浏览**：`D:\proj\` 就地翻目录；`Enter`/`→` 进入后切换浏览模式（面包屑导航 + 递归过滤）
- **键入即搜**：在资源管理器里直接打字，启动器带着当前目录就地过滤
- **文件对话框增强**：打开 / 保存对话框里自动唤出，输入路径直接跳转或填入
- **结果拖出**：把文件结果拖进微信 / 邮件 / IDE
- **应用 / 书签 / 命令**：开始菜单应用索引、Chrome/Edge/Firefox 书签、自定义关键字与网络搜索、内置计算器
- **本地优先**：索引、历史、配置都在 `%APPDATA%\lstr`，不联网、不上传

## 下载与安装

前往 [**Releases**](https://github.com/rosefinchlj/lstr/releases) 下载最新的 `lstr.exe`（单文件，免安装，x64）：

1. 运行 `lstr.exe`，首次启动同意一次 UAC（拉起只读扫描卷的索引 worker）
2. 常驻后双击 `Ctrl` 唤出；`Esc` 收起
3. 首次索引约 1~3 分钟，期间结果逐步补全

> 索引 worker 需要管理员权限才能读取 USN journal；拒绝 UAC 时程序仍可运行，但只能手工重建索引/退化为目录监视。

## 运行要求

- Windows 10/11（x64）
- 构建需要 Rust 1.85+
- 搜索后端只有一个：**自研内置索引**
  - 需要管理员授权（UAC 一次）拉起提权 worker
  - 首次构建约 1~3 分钟；构建期间结果暂不完整，完成后自动全量可用
  - 只覆盖本机固定 NTFS 卷；网络盘 / FAT32 / exFAT 不参与索引

## 索引引擎

程序只使用自研内置索引（不再依赖 Everything）。设置 → 搜索页只保留「内置索引实时层」：

| 选项 | 说明 |
|---|---|
| USN journal（默认） | 目录首扫后轮询 NTFS journal；快照完整且游标可信时**免扫直读**；卷打不开 / journal 不可用自动退回目录监视 |
| 目录监视 | `ReadDirectoryChangesW` 目录通知，零 USN FSCTL；worker 每次启动需整卷对账 |

- 索引卷勾选立即生效；实时层 / 噪声目录改动需重启 lstr
- 配置文件：`[index]` 的 `incremental`（`usn`/`watch`）；旧配置里的 `backend` 键会被忽略

## 构建与运行

```powershell
cargo build --release
.\target\release\lstr.exe
```

开发调试：

```powershell
cargo run
```

| 操作 | 行为 |
|---|---|
| 双击 `Ctrl` | 全局唤出 / 隐藏（默认热键；设置里可录制为双击 Space/Alt/Shift 或组合键） |
| 拖动顶部 12px 横条 | 移动窗口（顶部中央有拖动提示线） |
| 拖动左右/底部边缘或角落 | 调整窗口大小（420×160 ~ 1000×800；尺寸会写回配置） |
| 再次运行 `lstr.exe` | 已有实例会把窗口唤到前台（不会启动第二份） |
| 输入 | 40ms 合并防抖后搜索（请求在后台线程 latest-wins，不堆积） |
| 鼠标滚轮（结果列表上） | 滚动结果列表（超出可视高度时；↑↓ 选择会自动跟随滚动） |
| `↑` `↓` / `PageUp` `PageDown` | 选择 |
| `Home` / `End` | 跳到结果列表首行 / 末行（End 后继续滚动会自动加载更多） |
| `Enter` | 打开 |
| `Ctrl+Enter` | 在资源管理器中定位 |
| `Ctrl+Shift+Enter` | 以管理员身份运行 |
| `Ctrl+C`（输入框为空时） | 复制选中结果路径 |
| `Tab` / `Shift+Tab` | 切换类别 |
| `Alt+←` / `Alt+→` | 切换类别（任意状态都可用） |
| `Esc` | 收起窗口（保留输入与结果，下次唤出继续）；菜单 / 筛选菜单 / 设置 / 浏览态先逐层关闭 |
| `Ctrl+P` | 开/关预览面板 |
| 搜索框右侧**时钟图标** | 历史记录开关：关掉后空查询只显示常用应用，不再显示「最近使用」 |
| `Ctrl+G`（**已有文件对话框时**） | 打开文件夹搜索；选中文件夹 Enter 跳转，选中文件 Enter 填入。对话框可以位于 lstr 后面 |
| **打开/保存对话框出现时** | 自动唤出对话框模式（`dialog_assist`，设置里可关）。Quick Switch：空查询时顶部列出 Explorer **已打开的文件夹**，Enter 一键把对话框切过去 |
| `→`（选中文件夹，任意状态，含历史条目） | **就地展开**该文件夹（下钻到路径模式） |
| `→`（其他结果）/ `Ctrl+K` / `Shift+F10` / 右键结果 | 打开动作菜单：打开、定位、复制路径/文件名、管理员运行、打开方式、在终端打开、**从最近使用中移除** |
| `Shift+F10`（选中文件夹） | 同样是动作菜单（文件夹的 `→` 仍用于下钻，两者不冲突） |
| 把结果行**拖出窗口** | 以文件形式拖进其他应用（微信/邮件/IDE/Explorer），落下成功计入使用历史 |

类别：全部 / 文件夹 / 程序（`.exe`）/ 文件（排除 `.exe`）/ 应用 / 命令。

**筛选条（按钮操作，不用记语法）**：类别栏下方四个按钮，点开出菜单：

| 按钮 | 选项 | 背后等价语法（自动生成，用户无需输入） |
|---|---|---|
| 位置 | 全部位置 / 桌面 / 下载 / 文档 / 各盘符 | 引擎路径前缀 |
| 时间 | 不限 / 今天 / 7 天内 / 30 天内 / 一年内 | 引擎修改时间下界 |
| 类型 | 全部类型 / 文档 / 代码 / 图片 / 视频 / 音频 | 引擎扩展名集合 |
| 匹配 | 区分大小写 / 全词匹配 / 正则表达式（多选，可组合） | 内置引擎匹配选项 |

- 选中后有「✕ 清除」入口；筛选条件随每次搜索生效，面板收起后重置
- 有位置/时间/类型/日期/大小条件时只搜文件（应用/命令不参与，避免「选了 D 盘还出现微信」的困惑）；匹配选项只影响文件名匹配，不影响应用/命令
- 手输 `ext:` / `path:` 优先于按钮选择（两者冲突时不会叠加）；`path:` 收成**路径 chip**，「位置」与路径 chip 是同一语义、后写覆盖（选位置会清掉路径 chip）
- PathTyping（手输完整路径）本身是位置筛选，期间筛选条不生效；浏览模式下位置=当前目录，时间/类型/匹配仍可用
- **全词**：token 前后必须是词边界（ASCII 字母数字为词字符，`- _ . 空格 ( )` 等为边界）
- **正则**：整个输入作为表达式，不再解析 `ext:`/`path:`/日期/大小条件；按模式里的字面量走 n-gram 预筛，抽不到字面量时全盘扫描（可能较慢，输入新内容会取消旧查询）。非法表达式会在结果区给出解析错误，不发查询
- 匹配选项同样作用于**应用结果**；开启区分大小写/全词/正则后，应用的拼音与模糊兜底关闭，不再出现小写 `ai` 命中 `AI合成` 这类严格模式下的伪匹配
- 指定目录（Explorer 目录上下文 / 路径 chip `path:` / 浏览模式）只返回文件系统条目，应用、UWP、命令、关键字不会混入

**输入框条件（日期 / 大小 / 路径 / 盘符 / 范围）**

在输入框里写 `<字段><比较符><值>:`，冒号是提交符。**比较符前后默认不用空格**，加空格也兼容（`date>2026-11-10:` / `date > 2026-11-10:` 等价）。提交后条件收成输入框左侧的固定 chip（日期=琥珀色、大小=冷色、路径=紫色、盘符=绿色、范围=靛蓝），继续输入文件名即可。字段支持 `date` / `dm` / `mtime` / `日期` / `时间` / `修改时间`（日期）和 `size` / `大小` / `文件大小`（大小）；冒号可全角 `：`，比较符也接受全角 `＞ ＜ ＝ ≥ ≤`。所有 chip 共用一套交互：`←/→` 定位、`Ctrl+Bksp` 删除左邻、`Shift+Ctrl+Bksp` / 双击还原成文本编辑、`×` 单项移除、`Ctrl+Z/Y` 撤回/重做（含范围切换）。

| 输入 | 含义（本地时间，按天比较） |
|---|---|
| `date>2026-11-10:` | 修改时间晚于 2026-11-10 当天（≥ 11-11 00:00） |
| `date>=2026-11-10:` | 修改时间 ≥ 2026-11-10 00:00 |
| `date<2026-11-10:` | 修改时间早于 2026-11-10 00:00 |
| `date<=2026-11-10:` | 修改时间 ≤ 2026-11-10 全天 |
| `date 2026-11-10:` | 裸日期 = 省略比较符，等于「当天」（同 `date=…`） |
| `date 2026-11-01..2026-11-30:` | 闭区间（字段和日期之间保留一个空格） |
| `date 2025:` / `date=2025:` | **整年**（2025-01-01 ~ 12-31）；`date 2023..2025:` = 年区间 |
| `date 今年:` / `date 去年:` | 今年 / 去年整年 |
| `dm:>2026-11-10 ` | 紧凑写法（要求末尾有空格才提交） |

**相对日期**（值位置可写别名，chip 上显示别名、tooltip 显示换算后的真实日期）：

| 输入 | 含义 |
|---|---|
| `date=今天:` / `date 今天:` | 今天的文件 |
| `date>昨天:` | 昨天 00:00 之后（即今天起） |
| `date 本周:` / `date 上周:` | 本周一 00:00 ~ 周日全天 / 上周整周 |
| `date 本月:` / `date 上月:` | 本月 1 日 ~ 月底 / 上月整月 |
| `date 近7天:` / `date>=7天内:` | 含今天的近 7 天（`近N天` / `最近N天` / `N天内`，N ≤ 3650） |

| 输入 | 含义（字节，1 KB = 1024 B） |
|---|---|
| `size>10M:` | 大于 10 MiB |
| `size>=10MB:` | ≥ 10 MiB |
| `size<10KB:` | 小于 10 KiB |
| `size<=1G:` | ≤ 1 GiB |
| `size 10M..100M:` | 闭区间（字段和数值之间保留一个空格） |
| `size>10 MB:` | 数字和单位之间可加空格 |
| `size:>10M ` | 紧凑写法（末尾空格提交） |

- 大小单位：`B` / `K` / `KB` / `KiB` / `M` / `MB` / `MiB` / `G` / `GB` / `GiB` / `T` / `TB` / `TiB`，大小写不敏感；裸数字=字节。
- **输入条件的过程中不会触发搜索**：`date>`、`date > 2026-11-`、`size>10`、`C:`（编辑态）这类半截条件会暂停查询，结果区提示「正在输入日期/大小/盘符条件」；打完终结冒号收 chip 并搜索，编辑态下回车也可提交。
- **键盘删除/编辑条件**：`Ctrl+Backspace` 删光标左侧的 chip（先盘符、再大小、再日期；输入框在开头时等同删最右 chip），**普通 `Backspace` 不动条件**；`Shift+Ctrl+Backspace` 把左邻 chip 还原成等价文本进入编辑态（`:` 或回车重新提交，`Esc` 撤销），**双击 chip 本体**同样进入编辑。上面两种操作都支持虚拟 chip 光标：文本光标在开头时按 `←` 进入 chip 区，`←/→` 在 chip 间移动（点击 chip 本体也可定位），此时直接打字会自动回到输入框末尾。
- **条件撤回**：`Ctrl+Z` 撤回最近一次条件操作（提交/删除/编辑 chip、盘符还原路径、清空筛选），`Ctrl+Y` 或 `Ctrl+Shift+Z` 取消撤回；撤回后条件原文回到输入框并暂停查询，回车/冒号可重新提交。
- **条件联想**：输入 `s` / `d` 弹出 `size` / `date` 候选，`↑↓` 选择、`Enter` 进入编辑态（填入 `size>` / `date>`）、`Esc` 取消；弹框打开期间不发查询。
- **大小分段输入（遮罩）**：输入 `size>`（或编辑大小 chip）时值部分变成 **数字 + 单位两段**：默认 `10 MB`（暗色），`Tab` / `←→` 跳段、`↑↓` 数字 ±1 / 单位换档（B→KB→MB→GB→TB），数字从左覆盖默认值，回车提交（默认即 `> 10 MB`）；继续输入字母（如 `10M`）会退出遮罩转普通条件文本，冒号提交。编辑大小 chip 会按原区间预填数字/单位。
- **盘符 chip**：`C:` / `-C:` 与 `date:` / `size:` 一样在终结冒号处收成 chip；**只有当前真实存在的盘符才会收 chip**（不存在的 `Y:` 保留为普通搜索文本，不再生成条件）。`C:` 收 chip 后继续打 `\` 会自动还原成 `C:\` 进入路径浏览。
- **日期分段输入（遮罩）**：输入 `date>`（或编辑日期 chip）时值部分变成 年-月-日 三段结构化编辑——未输入的段显示**今天的默认值（暗色区分）**，`Tab` / `←→` 跳段、`↑↓` 加减（月回绕、日按当月天数夹紧）、数字从左覆盖默认值（年打满 4 位自动跳月，月 3 直接补 0 成 03 跳段），回车提交（未输完的段按显示值固化）；`-` / `/` / `.` 可直接当分隔符（当前段已输入数字才跳段，段空时忽略，所以 `2026-11-13` 连续打不会破模式），`:` 也可直接提交；输入其它字符（如「今」）退出遮罩转自由文本，别名照常可用。编辑已有日期 chip（Shift+Ctrl+Bksp / 双击）会以真实日期预填各段。
- **盘符 chip** 显示为 `C盘`（排除显示 `排除C盘`）。
- **路径 chip**：`path:D:\work `（空格或回车）收成紫色「路径」chip，走索引**递归**搜该目录的整个子树；带空格的路径用引号 `path:"C:\Program Files"`（右引号即提交）。chip 值只显示末尾部分（悬停看完整路径），双击还原成 `path:...` 文本可继续编辑，`×` / `Ctrl+Bksp` 移除。
- **范围 chip**：输入 `a ` / `f ` / `>` 收成「范围」chip（等同点 Tab / 按 Tab），与 Tab 高亮是同一状态的两种显示；`×` 回到「全部」。
- **输入历史**：`Ctrl+↑/↓`（非浏览/路径模式下也支持 `Alt+↑/↓`；结果为空时普通 `↑/↓` 也可）在输入框里上/下调出历史输入并立即搜索；连续打字/退格只保留最终形态，最多 100 条；一直按 ↓ 回到召回前的草稿。有结果时普通 `↑/↓` 仍是结果列表选择。
- **结果菜单**：`删除到回收站…` 只对本地文件/文件夹/程序出现（选中结果按 `Del` 同效），选中后弹出二次确认（`←/→` 切换「删除/取消」、Enter 执行当前焦点、Esc 取消），删除走系统回收站、只允许固定本地盘；删除成功后页脚显示「已移入回收站：xxx」和**「撤回删除」按钮**，点击即可把文件从回收站还原到原位置；`从最近使用中移除` 只在条目确实存在于「最近使用」历史时出现，普通搜索结果不再显示。
- 条件与筛选条、`ext:` / 路径 chip（`path:`）/ 盘符过滤是 AND；同一字段多条条件会合并成更紧的区间，日期、大小、路径、盘符可同时使用。
- 条件单独出现（输入框没有文件名）时列出所有满足条件的文件，不再显示「最近使用」。
- 日期/大小非法、区间为空时保留原文并在结果区顶部提示，不生成 chip，也不会把半截条件当文件名搜。
- 日期条件对文件/文件夹生效；**大小条件只对文件生效，文件夹一律排除**；「应用」「命令」类别下条件 chip 置灰、不参与查询。
- 修改时间/大小来自索引的 mtime/size 列（目录扫描写入）；USN 增量条目会在引擎空闲时回填，回填前不参与对应筛选。

查询语法：`ext:rs`、`path:E:\foo `（或 `path:E:\foo:`，收成路径 chip）、`*.html`（等价 `ext:html`）、`abc*`（前缀）、`*abc`（后缀）等。另有范围前缀（输入后即收成范围 chip）：

- `>`：命令
- `a 微信`：应用
- `f ext:rs`：文件

**相对路径分段**：带分隔符的查询按「路径末尾连续分段」匹配，比纯名字搜索更精确（`/`、`\`、全角 `＼` 都算分隔符，大小写不敏感、每段按子串匹配）：

- `DeepSeek\xxx`：名字含 `xxx`、且父目录含 `DeepSeek` 的条目（`aa\aa\DeepSeek\xxx` 这类深路径也可以直接写 `DeepSeek\xxx`）
- `aa\DeepSeek\xxx`：限定到更上层，必须按顺序连续出现
- `DeepSeek\`（尾部分隔符）：该目录下**所有后代**（递归）
- 绝对路径（`D:\...`、`\\server\...`）仍走下面的路径模式；含空白的输入按普通多词查询处理

**路径模式（就地翻目录）**：输入以 `盘符:\`（或 `盘符:/`）、`盘符:词` 或 `\\` 开头时直接列目录，不走索引：

- 输入 `D:\proj\` 列出子项，继续打字按名字/拼音过滤（`D:\proj\lis`）
- `D:\` 浏览 D 盘根目录；`D:prog` 等价于「D:\ 根目录 + 过滤 prog」
- **裸 `D:` 不再是路径浏览**：它和 `date:` / `size:` 一样收成输入框盘符 chip（只搜 D 盘）；要从根目录开始翻，打 `D:\`
- `Enter` / `→` 进入子文件夹；进入后切换成**浏览模式**：输入框只放过滤词，当前目录显示在筛选条下方独立一行的面包屑里（`此电脑 › D: › … › 当前目录`），不再把整条长路径塞进输入框
- 浏览模式：空过滤词列出直接子项；输入过滤词会在**当前目录下递归搜索子文件夹内容**（位置=当前目录，时间/类型/匹配选项同样生效）
- 浏览模式：`Alt+↑` / 过滤词为空时 `Backspace` 回上一级，`Alt+↓` 再回到刚离开的子目录；`Ctrl+L` 把完整路径放回输入框继续编辑；`Esc` 先清过滤词，再按一次退出浏览
- 面包屑祖先可点击跳转，中间放不下时 `…` 点开隐藏层级；普通结果里按 `→` 也会进入浏览模式
- 路径模式首屏 200 条，滚到底同样可继续加载（上限同「滚动加载上限」）

> 想全盘搜 D 盘：直接打 `D:` 收成盘符 chip（与 `c:` 前缀语法等价）；浏览根目录打 `D:\`。
>
> `D:\proj\` 是**就地翻目录**（只列直接子项，读目录不走索引）；`path:D:\proj ` 收成路径 chip 后是**递归搜子树**（走索引，空输入=列出该目录下所有后代）。两者互补。

**模糊匹配**（应用/命令）：子序列命中，`vsc` → Visual Studio Code、`wxin` → 微信（拼音容错）。命中字母逐个下划线标出，排序在子串/拼音之下，文件结果保持子串语义（内置索引另有文件名拼音辅助）。带**密度门槛**（平均每字符 ≥12 分）：词首/连续命中通过，纯散布（如 `sz` 散布在长拼音串里）一律拒绝。

**网络搜索 / 自定义关键字**：输入 `触发词 关键词`：

- `g rust` → 用 Google 搜索 rust；`bd 天气`、`gh egui`、`so lifetime` 等同理
- 打 `触发词` + 空格后收成橙色「搜索」chip：剩余文本全部当查询词，**只出「用 X 搜索…」这一行，本地索引整个跳过**（不跑文件搜索）；`×` 退出搜索模式、双击改回 `g ` 文本；只有「全部」页有搜索模式，此时其它条件 chip 置灰不参与
- 只输触发词（`g`）时 Enter 打开该站首页
- 触发词在 `config.toml` 的 `[[keyword]]` 里自定义（`url` 模板，或 `exec` 命令行模板；`{query}` 占位符）

## 排序规则

分数相加，从高到低；同分按字典序，文件夹微优（+5）。

| 分项 | 分值 |
|---|---|
| 名称完全一致 | 1000 |
| 名称前缀 | 800 |
| 名称子串 | 600 + 词首 `+30` + 位置越前最多 `+10` |
| 多词全含（`my report` → `my_report.pdf`） | 550 |
| 分隔符不敏感（`myreport` → `my_report.pdf`） | 520 |
| 拼音前缀 / 拼音子串 | 450 / 350 |
| 子序列模糊（应用/命令，`vsc` → VS Code） | 300~349 |
| 仅路径包含 | 200 |
| 历史使用 frecency | ×10，封顶 150 |
| 启动加权 | 应用/程序 +30，内置命令 +300 |
| 中文应用拼音命中 | +450 |
| 精确同名浅路径 | 每浅一层 +2（≤12 层） |
| 最近修改 | 7 天内 +15，30 天内 +8 |
| 路径调整 | 名字越短、路径越浅越高；USERPROFILE +20；当前目录 +300、父目录 +200；噪声目录扣分见下 |

**噪声降权**（人类几乎不会搜的文件堆，全部可在 **设置 → 噪声规则** 页增删改）：

- 临时/系统：`appdata/local/temp/`、`/temp/`、`/tmp/`、`windows/temp/`、`windows/winsxs/`、`windows/installer/`、`$recycle.bin/`、`system volume information/`（100~200 分）
- 依赖/构建：`node_modules/`、`bower_components/`、`.pnpm-store/`、`.yarn/cache/`、`.next/`、`.nuxt/`、`.svelte-kit/`、`.turbo/`、`.parcel-cache/`、`/target/`、`.cargo/registry/`、`.cargo/git/`、`.rustup/toolchains/`、`/pkg/mod/`（Go）、`site-packages/`、`__pycache__`、`.venv/`、`/venv/`、`.tox/`、`.mypy_cache/`、`.pytest_cache/`、`.ruff_cache/`、`.gradle/`、`.m2/repository/`、`.nuget/packages/`、`cmakefiles/`、`cmake-build-*`、`/obj/`、`/bin/debug/`、`/bin/release/`、`/vendor/`（80~120 分）
- VCS/缓存：`/.git/`、`/.svn/`、`/.hg/`、`/cache/`、`/.cache/`、`/.npm/`
- 浏览器 profile：Chrome / Edge / Firefox 的 `user data/`、`profiles/`（120 分）
- 临时文件名：`~$`、`.tmp`、`.partial`、`.crdownload`、`thumbs.db`、`desktop.ini`、`.ds_store`（60~100 分）

规则是「路径片段」匹配（正斜杠统一、不区分大小写），每条有独立分值（0~300），改完即时生效并写入 `config.toml` 的 `[rank].noise_rules`。

**例外**：搜索词本身出现在噪声片段里时不扣分——搜 `cache`、`temp`、`node_modules` 时你就是在找它们。内置索引的噪声排除同样只剔子孙：**噪声目录自身保留可搜**（搜 `node_modules`/`target`/`temp` 能找到目录本身并下钻），仅其内容不进索引以省内存；`packages` 这类常见 monorepo 源码目录不在排除表里。

## 配置

首次运行会生成：

- `%APPDATA%\lstr\config.toml`：热键、窗口尺寸、主题、强调色、行高、一屏结果数（`max_results`）、滚动加载上限（`max_load_results`，100–3000）、历史开关（`show_history`）、`[[keyword]]` 自定义关键字、`[rank]` 排序权重与噪声规则、`[index]` 实时层/卷/浏览器书签开关（`bookmarks`）
- 空查询 = 纯「最近使用」：清空历史后列表为空，不补常用应用；已安装应用看「应用」标签
- `%APPDATA%\lstr\history.db`：打开历史（SQLite，WAL 模式；删除即重置常用排序。老版本的 history.json 首次启动自动迁移并改名 .bak）

`[index]` 常用配置：

```toml
[index]
incremental = "usn"     # usn(默认,USN journal 增量) / watch(纯目录监视)
volumes = []            # 空 = 全部本机固定 NTFS 卷；如 ["C","D"]
exclude_noise = true    # 排除 node_modules/.git/target 等
candidate_cap = 2000    # 单次查询候选收集上限
journal_poll_ms = 500   # USN 轮询间隔，最小 100
```

主题内置 **Frost（浅色，默认）** 和 Obsidian（暗色）；设置浮层可切换，或改 `config.toml` 的 `theme.mode`。

关键字配置示例：

```toml
[[keyword]]
trigger = "g"
name = "Google"
url = "https://www.google.com/search?q={query}"

[[keyword]]
trigger = "np"
name = "记事本打开"
exec = "notepad {query}"
```

`url` 与 `exec` 二选一；`url` 的 `{query}` 会做百分号编码，`exec` 直接替换后按空格拆分程序与参数。改完执行命令 `重新加载`（或 `>reload`）即可生效，不必重启。

- **内置索引实时层**：默认 USN journal 增量（目录首扫后按 journal 追变化；快照完整且游标可信时免扫直读，卷打不开/journal 不可用自动退回目录监视）；设置 → 搜索 →「内置索引实时层」可切成纯目录监视（ReadDirectoryChangesW，零 USN FSCTL）

- **筛选条**：位置 / 时间 / 类型三个按钮 + 下拉菜单，把选择翻译成引擎查询规格；不需要用户记查询语法；筛选期间只搜文件
- **输入框条件 chip**：`date>2026-11-10:` / `size>10M:` / `C:` 这类短语在终结冒号处提交，收成输入框左侧固定 chip（等宽字体 + 日期琥珀色 / 大小冷色 / **盘符绿色显示 `C盘`**），hover 看语义、点 × 移除；`←/→` 在 chip 间移动或点击 chip 定位，`Ctrl+Bksp` 删左邻、`Shift+Ctrl+Bksp` 还原成等价文本编辑（`:` 或回车重新提交，Esc 撤销）、`Ctrl+Z` 撤回 / `Ctrl+Y` 取消撤回；打 `s` / `d` 弹出 size/date 联想，弹框期间不搜索；date 值支持分段编辑（年/月/日，默认今天、Tab 跳段、↑↓ 加减），size 值支持数字/单位分段（默认 10MB、↑↓ 加减/换档）；盘符 chip 与筛选条位置、`c:` 前缀语法求交（只有真实存在的盘符才收 chip）；比较符前后空格可选，支持全角比较符/闭区间、中英文段名、全角冒号；非法条件保留原文并提示；条件输入过程中暂停查询
- **结果列表滚动 + 加载更多**：首屏最多送 100 条候选（路径模式 200 条），窗口高度由「一屏结果数」决定（同时限制应用页/最近使用/Quick Switch 的条数），超出部分滚轮滚动、`↑↓`/`Home`/`End` 自动跟随，右侧有滚动条，底部提示「滚轮查看更多」；**滚到列表底部自动续拉**（每档翻倍，默认封顶 1000、设置里可调 100–3000，保留滚动位置与选中行），后端给不出更多时停止。上限越大单次响应越慢（会逐条刷新文件大小/时间并抓更多候选），建议 1000–2000
- 启动时隐藏到屏幕外，双击 Ctrl（默认）/ 托盘唤出（RedrawWindow 强制首帧重绘）；唤出时在光标所在屏幕**居中**

- 内置索引未就绪/不可用时在状态行提示；搜索线程会自动重连；设置里的「一屏结果数」「滚动加载上限」即时生效

## 已知问题

- 宽泛查询（如单个字符）首次可能较慢（全盘扫描/候选截断）；内置索引通常 <100ms。已用 40ms 合并防抖、候选集限制、滚到底加载更多缓解。
- 同名精确匹配的文件夹可能排在文件前面；同名去重每种最多保留 3 条（精确同名豁免，最多 6 条）。
- 中文输入法组合期间会按预编辑文本触发搜索（拼音搜索因此是实时的，但文件结果可能闪动）。
- 文件对话框增强只覆盖标准 Vista+ `#32770`；自绘对话框（部分 Electron/Office/WinUI）不保证；提权对话框会被 UIPI 拦截。
- `Ctrl+G` 只对**已打开的文件对话框**有意义；没有对话框时按它会提示先打开「打开/保存」对话框。lstr 盖在对话框上时也能识别（会枚举可见的 `#32770`）。
- 自动唤出只认标准 Vista+ `#32770` 文件对话框；自绘对话框（部分 Electron/Office/WinUI）不触发。用全局热键手动关掉后，下次对话框拿到前台时仍会再弹（关掉请用设置开关）。
- Quick Switch 的 Explorer 枚举走 `ShellWindows` COM（`LocationURL`），只收真实存在的文件系统目录；管理员权限的 Explorer 窗口枚举不到。
- 非 NTFS 卷（exFAT U 盘、网络驱动器）不参与索引，搜不到；索引只覆盖本机固定 NTFS 卷。
- 筛选条只在普通搜索生效：路径模式（`D:\`）与「应用/命令」类别下按钮不参与查询。
- 「全部」首屏展示排序后的前 100 条候选（路径模式 200 条），滚到底继续加载到设置上限（默认 1000、最多 3000）；总数完整显示在底部。
- USN journal 被重置/回绕（journal_id 变化或保存的游标超出范围）时，该卷会退回目录扫描对账；目录监视在大量文件变更/通知缓冲溢出时也会触发整卷对账，可能消耗一段时间的 I/O。
- 应用索引 90s TTL 重建在 worker 线程同步执行（几十 ms），重建瞬间 UWP 条目会短暂消失（懒加载约 2 秒后回来）。
- 保存对话框的 `is_save` 通过标题识别（保存/另存/Save）；不同语言/应用可能漏判。
- UWP 枚举当前走 PowerShell 回退（后台线程，约 2 秒后可用）；COM 版本需补 `Win32_UI_Shell_Common` feature。
- 设置浮层、「打开方式…」「管理员运行」已接线但未逐一自动化验证（键盘自动化焦点不稳，建议手测）。
- 窗口尺寸/位置只在本次运行内保持；重启后回到配置宽度并在唤出时居中。
- 托盘图标、单实例已验证；托盘右键菜单未做自动化测试。
- 未签名，首次运行可能触发 SmartScreen。
